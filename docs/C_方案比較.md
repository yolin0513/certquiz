# C. App 能做到什麼程度：方案比較

依據 `B_考古題可行性.md` 的結論。題數都是**估計**，不是承諾；「使用者 要出的力」以他本人要花的時間為準，不算 Claude 的工作量。

## 前提（決定方案的兩件事）

1. **使用者的其他 App 都是 public repo＋GitHub Pages**。照這個做法，放進 repo 的題目＝公開散布。所以「題目放哪裡」比「題目從哪裡來」更決定版權風險。
2. **官方公開又確定能散布的現成題目，三張證照加起來是 0**：TABF 的近三期試題公開免費，但沒有授權條款、著作權法 §9 是否適用未確認；微軟的練習題明確不能搬。

---

## 方案一：只做練習引擎＋題庫格式，題目由使用者自己匯入

- **內容**：App 本身不附任何題目。提供匯入功能（CSV／JSON／一種好手打的純文字格式），匯入的題目只存在使用者手機的 IndexedDB，不進 repo。
- **題數**：從 0 開始，看使用者匯入多少。
- **使用者 要出的力**：**很大**。手上的書要自己打字或拍照 OCR 再校對（每題含 4 個選項＋解析，一題估 2～4 分鐘，200 題就是 7～13 小時）；阿摩、MeasureUp 這類平台通常不能匯出（→推論）。
- **版權風險**：最低（個人使用、不公開）。
- **代價**：App 一打開是空的；換手機要靠備份檔搬題目。

## 方案二：附官方公開免費的題目

- **內容**：只有 TABF 銀行內控近三期筆試試題（AZ-900、AI-901 沒有可附的題目）。
- **題數**：約 630 題（法規約 150、一般金融實務約 240、消費金融實務約 240，→推論）。只考一組的話約 390 題。
- **兩種做法，風險差很多**：
  - **2A｜本機轉檔、不進 repo（建議）**：寫一支轉檔腳本，使用者（或經他同意由 Claude）從 TABF 官網下載 PDF，在本機轉成題庫檔；轉出的檔案列入 `.gitignore`，公開部署的版本**不含**這些題目，使用者用「匯入」放進自己手機。版權風險低（個人使用）。
  - **2B｜放進 repo 公開部署**：要先向 TABF 書面確認可以重製散布，或確認著作權法 §9 適用。沒確認前不建議。
- **使用者 要出的力**：小～中。下載 18 個 PDF（或同意由 Claude 下載）；抽查轉檔結果（PDF 是 A3 雙欄排版，→推論轉檔可能有斷行、題號錯位，需要人工抽查，估 1～2 小時）。
- **代價**：
  - **只有近三期**，每過一期最舊的就下架，題量不會自然累積（除非每期自己留存）。
  - **法規會過期**：官方明說舊題答案可能因法規修訂而錯。App 要顯示每題的法規基準日；轉檔時不會自動知道哪題已經錯。
  - 官方答案 PDF 只有正確選項，**沒有解析**。解析要另外寫（見方案三）。

## 方案三：依官方大綱與公開法規「原創」練習題（由 Claude 生成）

- **內容**：
  - AZ-900、AI-901：依官方 study guide 的每一個考點出題，解析附上 Microsoft Learn 對應文件的連結。
  - 銀行內控：依**法規條文本身**出題（法律、命令條文依著作權法 §9 第 1 款不受保護，可以引用），每題附條號與法規版本日期；實務題依法規與公開的主管機關函令出。
- **題數**（估）：AZ-900 約 200～300 題、AI-901 約 150～250 題、銀行內控約 200～400 題。可以分批做。
- **必須寫清楚的限制**：
  - **AI 生成的題目不等於考題**，難度、措辭、重點分布都可能跟真實考試不同。App 裡每一題都標來源「原創（AI 生成）」，跟官方題分開統計。
  - **正確性要查核**：法規題要對照全國法規資料庫的現行條文；雲端題要對照 Learn 文件。Claude 可以做第一輪查核，但使用者要抽查（內控尤其需要熟悉實務的人看）。照 JLPT 的慣例，每批至少抽 40 題。
  - AI-901 的 55～60% 是 Foundry／SDK 實作，選擇題只能練到「看得懂程式碼、知道該用哪個服務」，練不到真的動手做。
- **使用者 要出的力**：中。每批抽查（40 題約 1 小時），決定出題範圍與優先順序。
- **版權風險**：低。原創題目，不抄書商、不碰考題。微軟這邊只要不是根據考後回憶出題，就不違反考生協議。

## 方案四（建議）：一＋2A＋三的組合

- 引擎與題庫格式照方案一做，**支援匯入**（使用者手上有書、有付費題庫時可以用）。
- 銀行內控：官方近三期試題走 **2A 本機轉檔**＋**方案三的法規條文原創題**（補解析、補題量、跟上現行法規）。
- AZ-900、AI-901：只能走**方案三**。
- 公開部署的版本只含原創題；TABF 官方題只在使用者自己的手機裡。
- **題數**（估）：銀行內控 600～1000（官方約 390～630＋原創 200～400）、AZ-900 200～300、AI-901 150～250。
- **使用者 要出的力**：中。下載 PDF（或授權）＋各批抽查。
- **版權風險**：低。

### 為什麼建議方案四

1. 銀行內控是本 App 的主軸，**官方真題是最貼近考試的練習**，2A 讓使用者用得到、又不必先解決公開散布的授權問題。
2. 微軟兩張沒有任何可合法收錄的現成題目，原創是唯一能讓 App 不是空殼的路。
3. 匯入功能做起來不貴，保留給他手上的書和付費題庫。
