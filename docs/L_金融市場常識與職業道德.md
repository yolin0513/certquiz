**兩版差異**（門檻依未配對題的相似度分布定：常識在 0.3～0.6 之間 0 題，兩群之間有空檔）：

- 限度：分類靠文字相似度；「新增」裡可能有大幅改寫的舊題（相似度低於 0.3 就分不出來）。
