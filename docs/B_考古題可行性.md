## 1. 銀行內部控制與內部稽核測驗（TABF）

### 1.1 官方歷屆試題

- 頁面：https://www.tabf.org.tw/LicenseHistoryExam.aspx 〔原文，我自己核對過〕
- 頁面原文說明：「僅提供筆試測驗近三期試題作為參考；各類歷屆試題及解答，係以測驗當時所適用法規為準。嗣後如因法規修訂，致試題不適用或解答有誤時，煩請讀者自行更正。」〔原文〕
- 目前提供的期別〔原文〕：
  - 一般金融：第 47、48、49 期（`?PHID=419`、`441`、`454`）
  - 消費金融：第 47、48、49 期（`?PHID=422`、`443`、`455`）
- 每期 3 個 PDF：法規卷、實務卷、答案。例：第 49 期一般金融 `https://service.tabf.org.tw/BEExam/Doc/ExamHistoryEdit/663412-1.pdf`（法規）、`-2.pdf`（實務）、`-3.pdf`（答案）〔原文，代理讀到〕
- 格式：代理開過第 49 期一般金融的法規卷與實務卷，**各 2 頁 A3 橫式、Word 產生、文字可擷取，不是掃描檔**〔原文，代理讀到〕。答案 PDF 只確認有連結、沒有打開。
- 不需要登入或付款〔原文，代理直接取得〕。
- TABF FAQ 原文：「本院並未出版任何『題庫』，歷屆試題(前3屆/期)可在本院網站…免費下載」〔原文〕
- **題量**（→推論）：每期法規 50＋實務 80；法規卷兩組共用。三期合計：法規約 150、一般金融實務約 240、消費金融實務約 240，**不重複約 630 題**。消費金融的法規卷是否確實與一般金融那份完全相同，沒有打開比對。
- **只有近三期**：每過一期，最舊的一期就會從網站下架（→推論，依「僅提供近三期」這句話）。所以題量不會累積，除非使用者每期自己留存。
- **法規會過期**：官方明說舊題的答案可能因法規修訂而錯。App 必須能標示「這題的法規基準日」和「已知過期」。

### 1.2 TABF 的電腦應試

電腦應試題目不公開（→推論，因為官方只公布筆試題；SFI 簡章也寫電腦應試「不得要求調閱試題」，TABF 這邊沒讀到對應條文）。

### 1.3 第三方資源（只記錄存在，沒有複製內容）

- 千華《銀行內部控制與內部稽核測驗 焦點速成+歷屆試題》〔標題／摘要〕https://www.eslite.com/product/10012022712683109715006
- 《銀行內部控制與內部稽核資格測驗經典講義與試題（115年最新版）》〔標題〕https://www.eslite.com/product/1001123071597207
- 阿摩線上測驗（yamol.tw）已收錄第 49 期法規卷，有登入機制，是否付費未確認〔摘要〕

- 這些都有兩個問題：**版權**（書商的解析、編排是他們的著作）與**正確性**（舊題的答案可能因法規修訂而錯，書商未必更新）。

### 1.4 版權：官方試題能不能放進 App（**未定，關鍵**）

- TABF 歷屆試題頁與 FAQ **都沒有著作權聲明或再利用條款**〔原文〕。
- TABF 的其他簡章寫「試題卷一律回收」、「試卷未繳回而涉及侵佔本院試題資料者，本院將依法追訴」〔原文，111 年職業道德簡章〕→推論：TABF 把試題視為自己的資料。
- 台灣《著作權法》第 9 條第 1 項第 5 款：「依法令舉行之各類考試試題及其備用試題」不受著作權保護。這張測驗**是法規要求取得的**，所以有可能適用；**但我沒有找到主管機關對「民間機構辦理的證照測驗」是否屬於「依法令舉行」的明確函釋**。查到的資料：
  - 智慧財產局解釋「依法令舉行」指依我國法令；所舉例子都是教育體系內的考試〔摘要〕。
  - 智慧財產局簡報說它不是各類考試的主管機關，個別考試是否屬於「依法令舉行」應洽該考試的主管機關確認〔摘要〕。
  - 來源：[智慧財產局簡報 PDF](https://www.tipo.gov.tw/wSite/public/Attachment/0/f1747881968056.pdf)、[法律百科](https://www.legis-pedia.com/QA/question/1928)、[理律新知](https://www.leeandli.com/TW/Newsletters/2254.htm)（皆〔摘要〕）。
- 選擇題的答案本身通常不受保護；但**解析**如果是自己寫的就是自己的著作，如果抄書商的就不行〔摘要〕。
- **兩種用法要分開看**：
  - **使用者 自己下載、轉成本機題庫、只在自己手機用**：→推論，屬個人非營利使用（著作權法第 51 條的範圍），風險低。
  - **把題目放進 repo、部署到公開網站**（使用者的其他 App 都是 public repo＋GitHub Pages）：等於公開散布。在 §9 適用與否未確認、TABF 沒有授權條款的情況下，**不建議**。要做的話先向 TABF 書面詢問（電話 (02)3365-3666 #1；是否要寄信由使用者決定，我不會代寄）。

### 1.5 證基會（只在範圍改成「企業內部控制基本能力測驗」時才相關）

- 考題下載頁 https://www.sfi.org.tw/Node?id=217 ，只提供「前兩季」筆試試題與答案〔摘要〕。企業內控的檔案：`https://examweb.sfi.org.tw/Download/01/36.pdf`（答案 `36a.pdf`）等〔標題，沒打開〕。

## 2. Microsoft AZ-900 與 AI-901

### 2.1 官方免費資源

| 資源 | AZ-900 | AI-901 | 能不能放進 App |
|---|---|---|---|
| Study guide（大綱） | 有，2026-07-20 版〔原文〕 | 有，2026-04-15 版〔原文〕 | 可以**參照大綱自己出題**；大綱文字本身不搬，只用考點結構 |
| Practice Assessment | 免費、無限次、**要登入 Learn**〔原文〕；題數未取得（未登入看不到） | 搬到 AI Skills Navigator，**要登入**〔原文，引自官方頁的說明，沒開那頁〕；題數未取得 | **不能**。Learn 使用條款：僅限個人非商業使用，未經書面同意不得複製、散布、改作〔原文〕https://learn.microsoft.com/en-us/legal/termsofuse |
| Exam sandbox | https://aka.ms/examdemo（只示範介面與題型，不是題目） | 同左 | 不搬題；只參考題型 |
| 免費教材 | Learn 三條 learning path、AZ-900T00 課程（有繁中）〔原文〕 | AI-901T00 課程（有繁中）〔原文〕；learning path 頁面有互相矛盾的說法 | 可以當出題依據，不搬原文 |

- 官方註明 Practice Assessment 的題目「由 AI 協助撰寫」，而且「不是考試上的題目」〔原文〕。
- 一個實用的用法：**使用者 自己登入 Learn 做官方 Practice Assessment**（免費），App 不收那些題目，只拿來檢驗自己。這不需要 App 做任何事。

### 2.2 保密協議（NDA）與 braindump

- **Microsoft Certification Exam – Candidate Agreement**〔原文〕https://learn.microsoft.com/en-us/credentials/support/certification-exam-candidate-agreement
  - 第 1 條 Confidentiality：禁止散布、複製、發表、**摘要（summarize）**、拍照、錄製或張貼任何考題、答案、圖表等考試內容。
  - 第 2 條 Misconduct：明列使用「braindump material」、未經授權公開考題（不論有無答案）。後果是禁考、成績作廢、不退費。
- **Exam and assessment security policies**〔原文〕https://learn.microsoft.com/en-us/credentials/support/exam-and-assessment-lab-security-policies
  - 考試內容是 Microsoft 的機密智慧財產；禁止討論或張貼考後回憶的考點；brain dump 業者侵害 Microsoft 智慧財產權；罰則包括撤銷證照、永久禁考。
- **對 App 的意思**：不能收錄任何真實考題、考後回憶、dump 題庫——不只是版權問題，使用者自己用了也可能被撤銷證照。

### 2.3 第三方

- **MeasureUp**：Microsoft FAQ 指名的付費官方練習測驗供應商〔原文〕。AZ-900 有產品，題數說法 151–188 題不一〔摘要〕；AI-901 的產品在已檢索範圍內未見（檢索了一般搜尋）。只能在 MeasureUp 自己的平台上用，不能匯出到 App（→推論，未讀其條款）。
- **Dumps 網站、Udemy 題庫**：搜尋結果大量存在〔標題〕。沒有造訪。依 Microsoft 定義屬侵權與違反考生協議；而且 AI-900 已退役、AZ-900 剛改版，舊題庫正確性也有問題。
- Microsoft FAQ：不審查第三方教材、不為其內容負責〔原文〕。
