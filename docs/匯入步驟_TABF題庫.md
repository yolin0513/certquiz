# 把題庫放進手機

> 2026-10-13 依實際流程改寫：使用者自己已經照這個流程匯入成功過（舊版文件寫的是 App 還沒做好時的設計，步驟和畫面都跟實際不符）。
> 題庫檔只給你自己用：不會放上網站、不會進公開的 repo。

## 檔案在哪

電腦的 `D:\Claude\App\CertQuiz\data\local\import\` 資料夾：

- `bic-匯入包.json`：銀行內控（910 題，去掉重複後可練 801 題）
- `ethics-匯入包.json`：金融市場常識與職業道德（116 年版考試範圍 1,174 題）

## 步驟

1. 把檔案傳到手機，存到「檔案」App（LINE 傳給自己、雲端硬碟、Email 都可以）。
2. 打開 App → 首頁最上面的「設定」→「匯入題目」→ 選那個檔案。
3. 畫面會先寫題數（例如「銀行內控：910 題，去掉重複後可練 801 題。」），按「確定匯入」。看到「匯入完成」就好了。

## 要知道的

- 重新匯入新版的檔案會整份換掉舊的題目；作答紀錄、錯題、標記都會保留。
- 題目存在這支手機的瀏覽器裡。換手機或資料被清掉時，要重新匯入題目，作答紀錄用「設定 → 備份與還原」帶回來。
