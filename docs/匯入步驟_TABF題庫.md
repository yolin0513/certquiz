# 把 TABF 官方題庫放進手機（給使用者）

> **草稿**：App 還沒做好，下面的步驟是設計，做好後會在手機上實際走一遍再定稿。
> 這份題庫只給你自己用：檔案不會放上網站、不會進公開的 repo。

## 你需要的

- 一個題庫檔：`TABF題庫_一般金融_第47-49期.json`（約 140 KB），在電腦的 `CertQuiz/data/local/` 資料夾裡。
- 手機上已經打開過練習 App 的網址（建議先「加入主畫面」）。

## 步驟

1. **把檔案傳到手機**（擇一）
   - LINE：電腦版 LINE 把檔案傳到「Keep」或傳給自己 → 手機上點開檔案 → 「儲存」（iPhone 存到「檔案」App；Android 存到「下載」）。
   - Google 雲端硬碟：上傳 → 手機上打開 → 「下載」或「傳送副本 → 儲存到檔案」。
   - Email 寄給自己 → 手機上下載附件。
2. **在 App 裡匯入**：打開 App → 設定 → 「匯入題目」 → 選剛剛存下的檔案。
3. App 會顯示「匯入 390 題：法規 150、實務 240」之類的確認訊息。看到數字對了就完成。

## 要知道的

- 題目存在**這支手機的瀏覽器裡**。換手機、清除瀏覽器資料、或刪掉 App，要重新匯入一次（作答紀錄要另外用「備份」帶走）。
- 再匯入一次同一個檔案不會重複：每一題有固定編號，會直接覆蓋成同一份。
- 題目來源：台灣金融研訓院官網公開的近三期筆試試題與答案。答案以**當期測驗時的法規**為準；法規修訂後可能已經不適用，App 會在每題顯示「法規基準：第 N 期（年月）」。
- 官方答案只有正解、沒有解析。

## 換電腦時，題庫檔怎麼重新產生

在電腦上的 `CertQuiz` 資料夾：
1. 從官網重新下載第 47～49 期一般金融的法規卷、實務卷、答案（共 9 個 PDF），放到 `refs/tabf/past/`（或請 Claude 代為下載）。
2. 執行 `python scripts/import_tabf.py`，會重新產生 `data/local/` 裡的題庫檔。
