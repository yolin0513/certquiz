> **這份文件最重要的量測（2026-10-14；詳見第八節）：核對本身有雜訊。**

> - C2、C4、C5 只有 32 段被判過兩次，0 段不一致。**數量太少，不能讀成「雜訊 0%」**。

> - **這份教材「有多少說明」，受我們的流程影響大於題目本身**：各章比例是「在這套規則與這些退回之下產出了這麼多」，不是「這些題只能解釋這麼多」。

格式已定案（使用者 2026-10-13 確認信用卡章）：
- 每題的說明只有三種：法規重點、我們寫的（未查證）、沒有說明。
- **法規重點**：寫作規格是「條號 → 一句重點 → 指出選項」，完整條文收在展開裡。
- **我們寫的（未查證）**：沒有外部依據的說明。
- **沒有說明**：純背的題；每一章的章首都要有一句「沒有說明的題＝純粹要背的數字或規定，不是漏做」。

- 金融市場常識與職業道德：116 年版考試範圍 **1,174** 題。

## 一、兩層各自怎麼核

### 法規重點（乙）：全量核，不抽樣（Dispatch 定案）

這一層有真值，就是條文全文，所以每一題都核。

1. **判有沒有依據**：兩個獨立代理各自讀考試當時那一版的全文，判斷條文是否寫出正解。兩邊都判「對得上」、而且條號相同，才算有依據；不一致的就不放法規重點。
2. **寫摘要**：照寫作規格寫一句摘要。
3. **核摘要**：另一個獨立代理對照全文逐題判「一致」或「偏離」。偏離的修正後，由**新的代理整份重判**，不只重判改過的那幾題，直到全部一致。
4. **防竄改**：建置只用最新一輪鎖定後、摘要檔沒被改過的版本（已實作，突變驗過）。

### 我們寫的（丙）：抽樣複核

**這一層沒有真值。** 「寫得對不對」不是可以核對的東西，不列為核對項目。

能核對的只有下面五項（**C3 機械全量、C1 全量**、其餘抽樣；2026-10-14 Dispatch 補：C1 是五項裡唯一會直接害他答錯的，所以全量）：

| 代號 | 核對什麼 | 怎麼判 |
|---|---|---|
| **C1 不跟官方正解矛盾** | 說明的結論指向官方正解；沒有暗示別的選項才對，也沒有說官方答案錯 | 有任何一處矛盾 → 不合格 |
| **C2 沒有延伸**（**已修訂**，見下方「C2 修訂」；這一列是原版，保留） | 只解釋為什麼正解對；沒有引進題目和選項裡都沒有的數字、期限、金額、條件或規定 | 出現新的數字或條件 → 不合格（這是最容易錯的部分） |
| **C3 沒有偷渡依據** | 不出現法規名稱、「依據」、「依…規定」、「主管機關規定」等 | **建置時機械檢查，全量**；出現就擋下 |
| **C4 不是空話** | 標「說明」的段落要給出比重述答案更多的理由 | 只是把答案換句話說 → 不合格（應該改成「沒有說明」） |
| **C5 內部一致** | 提到的選項編號對得上；段落沒有自相矛盾 | 有錯 → 不合格 |

### C2 修訂（2026-10-13；使用者核准、Dispatch 定案；**修訂後才重做**）

**改了什麼**：C2 從「不得引進題目和選項裡沒有的任何數字、期限、金額、條件或規定」，改成兩分：
- **禁止（照舊）**：引進題目與官方正解之外的**具體事實**——數字、期限、比例、金額、條號、法規名稱、機構名稱。這一類會讓讀者背錯，而且看起來像有依據。
- **允許（新）**：引進**一般性的道理**來解釋為什麼正解是對的（例如「要經法院」「較難證明對方收到」）。這一層本來就標著「我們寫的（未查證）」，標籤就是給這種用的。
- **界線**：那句話拿掉之後，讀者仍然知道「選這個是因為什麼道理」→ 是道理；那句話本身就是一條可以被背起來、而且可能被考的事實 → 是具體事實。**拿不準就當具體事實處理（從嚴）。**

**為什麼改**：原規則實際上等於禁止解釋——要講出理由，幾乎都得帶進一個題目裡沒寫的前提。證據：第二章照原規則做完，54 題裡「沒有說明」42 題（78%）；信用卡章「我們寫的」從 23 降到 12。

**沒有跟著改的**：**C1（不跟官方正解矛盾）維持全量、維持從嚴。** 它是五項裡唯一會直接害讀者答錯的；修 C2 不代表整體標準放寬。C3（法規名稱、依據字樣，機械全量）、C4、C5 也不變。

**適用範圍**：信用卡章與第二章都用修訂後的規則重做（兩章要一致）；之後各章照修訂版。

**判斷修法有沒有用的唯一依據**：新規則下兩章的「沒有說明」各剩幾題。**如果還是超過一半，表示問題不只在 C2，要回頭再看。**

**C1 全量怎麼做**：每一段都由一個獨立代理看「題目、官方正解、說明」，判「不矛盾／矛盾」。每段很短，不需要讀法規，所以做得到全量（內控約 700 段、約 7 個代理、約 0.4M token）。矛盾的那一段由新的寫手重寫，再由新的核對者重核，直到不矛盾。下面的抽樣仍然照樣抽 C1，當作第二道檢查。

**抽樣**（C2、C4、C5，以及 C1 的第二道）：
- 以「寫手批次」分層：同一個寫手代理一次寫的 50 題算一批，因為錯誤會跟著同一個寫手出現。
- 每批隨機抽 **8 段或 15%**，取較多的一方。
- 抽樣用固定種子：20261014 加上批次編號，可以重現。
- 抽樣在那一批**寫完並鎖定之後**才進行。

**誰核**：
- 由另一個獨立代理核，不是寫手本人。
- 核對者只看題目、官方正解、說明本身，看不到是哪個寫手寫的。

**不合格怎麼處理（事先定）**：

| 抽到的結果 | 處理 |
|---|---|
| 抽樣裡有任何一段 C1 不合格（表示全量 C1 漏掉了） | **整批退回**，由新的寫手重寫，再重新做全量 C1 與抽樣 |
| C2、C4、C5 合計不合格 ≥ 2 段 | **整批退回**重寫 |
| C2、C4、C5 合計不合格 1 段 | 只修那一段，由新的核對者重核那一段；**另外加抽 8 段**，加抽若再有不合格就整批退回 |
| 全部合格 | 該批通過 |

**防竄改**：涵蓋這一層。每批通過時鎖定雜湊；建置時只要「我們寫的」檔在鎖定後被改過，就擋下。

**限度（照寫）**：
- 抽樣核的是形式（矛盾、延伸、依據、空話、一致），不是內容對不對。
- 通過的批次裡，沒被抽到的段落仍可能有錯。
- 寫手、核對者都是 Claude。
- 畫面上的「未查證」標示就是為了這一點。

## 八、核對有雜訊；已通過的批次不再重抽（Dispatch 2026-10-14 決定）

**實例**：T05 的 w31 在第 1、3、5 輪抽樣都通過。第 7 輪，一個核對者把**同一段、一個字都沒改過**的文字判成 C1 不合格，整批退回。同一段文字被看了四次，判出兩種結果。

**這是核對本身的雜訊，不是品質變差**。每重抽一次已通過、沒改過的內容，就多一次抽中雜訊的機會。**退回次數多，不代表品質差，而是看的次數多。**

**量出來的雜訊**（`python -u scripts/textbook_review_noise.py`；以「題號＋說明文字完全相同」當同一段，統計它被重複判定的結果）：

| 項目 | 被判 2 次以上的段 | 前後判定不一致的段 | 兩兩比對不一致 |
|---|---|---|---|
| C1 | 343 | 8（2.3%） | 17／1,310 對（1.3%） |
| C2／C4／C5（各自） | 32 | 0 | 0／62 對 |
| 抽樣四項合起來（決定整批去留的判定） | 32 | 1（3.1%） | 1／62 對（1.6%） |

- 讀法：同一段文字讓兩個核對者各判一次 C1，約 1.3% 的機會判得不一樣。C2／C4／C5 被重複判定的只有 32 段，數量太少，0 不代表沒有雜訊。
- 影響：一次抽 16 段，每段有 1% 左右被誤判的機會，整批就有約 15% 的機會因為雜訊被退回。退回又會讓寫手更保守（常設規則 27），所以雜訊最後變成「說明變少」。
- 這也是所有「兩個代理一致」結論的參考值：兩個 Claude 判同一件事，約有 1～2% 的機會不一致。一致不等於對（常設規則一直這樣寫），不一致也可能只是雜訊。

**決定**：已通過的批次不再重複抽樣。
- **這不是放寬標準，是移除一個隨看的次數累積的偽陽性來源。** 第一節的表本來就是「全部合格 → 該批通過」。先前腳本每一輪重抽整章所有批次，比事先寫的規則多看了好幾次，是我實作上的偏差。
- 腳本（`textbook_ours_check.py sample`）：某一批在先前任何一輪的抽樣或加抽裡全部合格，而且那一批每一段的文字都跟當時一樣，就不再抽；單子結尾會列出跳過了哪幾批。
- **沒有改的**：C1 全量、C2 修訂版、C3 機械檢查、C4、C5 的判準，以及退回規則（抽樣 C1 不合格 → 整批退回；C2／C4／C5 ≥ 2 → 整批退回；1 段 → 修＋加抽）。
- C1 全量每一輪仍然重判全部段落（C1 從嚴、全量，不動）。它也會碰到同樣的雜訊，但全量 C1 判矛盾只會退回那一段，不會整批退回。

**這份教材「有多少說明」，我們的流程影響大於題目本身**（Dispatch 要留下的話）：
- 將來任何人看到各章「沒有說明」的比例，要知道那**不是**「這些題只能解釋這麼多」，**而是**「在這套規則與這些退回之下，產出了這麼多」。

## 十二、金融市場常識不做（紀錄）

- **決定日期**：2026-10-14。使用者核准「只做職業道德，金融市場常識不做」，由 Dispatch 轉達。
- **依據的數字**（第十節）：116 年版考試範圍的金融市場常識 558 題，固定種子抽 20 題，兩個獨立判斷者各自判。**甲（要背的事實：數字、期限、比例、機構名稱、分類歸屬）14 題（70%）**，乙（有道理可講）6 題（30%），兩人 20／20 一致。職業道德用同樣的方法是甲 25%、乙 75%。
- **為什麼據此不做**：「我們寫的」只能寫一般道理，不能引進具體事實（C2）。要背的事實題大概率會變成「沒有說明」，做出來大約七成空白，力氣花在寫得出說明的那一科比較值得。另外，這一科題目點名法規的只有 3.4%（25／558），「法規重點」那一層也做不起來（第二節）。
- **這個決定的限度**：
  - 抽樣只有 20 題，70% 的誤差大約正負 20 個百分點（真實比例可能在五成到九成之間）。
  - 兩個判斷者用同一份定義、看同一份單子，一致不等於對（常設規則 28）。
  - 「甲」是判斷者看題目分的類，不是實際寫寫看的結果；實際寫，可能比七成好，也可能更差。
- **將來要重新考慮時**：先把抽樣擴大（例如 60 題），或直接拿一章試寫一批、看實際的「沒有說明」比例，再決定。這一科沒做，是上面這個決定的結果，不是漏做。

**事後驗證：當初「只做職業道德」的抽樣決策（2026-10-14 寫，是做完之後才知道的，不是當時就知道）**
- 決策時的依據（第十節）：各抽 20 題，職業道德約 75% 有道理可講，金融市場常識約 30%。
- 做完的結果：職業道德 616 題，88% 有說明（我們寫的 541）。內控 801 題是 42%（法規重點 13%＋我們寫的 42%＝55% 有某種說明，「我們寫的」單層是 42%）。
- 方向一致：抽樣說「道德寫得出說明」，全量結果是 88%，比內控「我們寫的」那一層的 42% 高一倍以上。這支持當時根據 20 題做的決定。
- 限度照寫：
  - 75% 和 88% 量的不是同一件事。75% 是判斷者看題目分的類，88% 是寫手寫出來、又通過複核的說明。兩者方向一致，但數值不能直接比。
  - 金融市場常識沒做，所以「常識做出來會七成空白」這一半沒有被驗證，仍然只是推估（第十二節）。
