# M. 教材全量：抽樣複核方案與工作量（2026-10-14，**開工前寫定並提交；事後不調**）

格式已定案（使用者 2026-10-13 確認信用卡章）：
- 每題的說明只有三種：法規重點、我們寫的（未查證）、沒有說明。
- **法規重點**：寫作規格是「條號 → 一句重點 → 指出選項」，完整條文收在展開裡。
- **我們寫的（未查證）**：沒有外部依據的說明。
- **沒有說明**：純背的題；每一章的章首都要有一句「沒有說明的題＝純粹要背的數字或規定，不是漏做」。

母體：
- 內控：可練 **801** 題。其中有乙候選（題目點名法規、而且查得到考試當時版本）的 **119** 題，信用卡章的 14 題已經做完。
- 金融市場常識與職業道德：116 年版考試範圍 **1,174** 題。

## 一、兩層各自怎麼核

### 法規重點（乙）：全量核，不抽樣（Dispatch 定案）

這一層有真值，就是條文全文，所以每一題都核。

1. **判有沒有依據**：兩個獨立代理各自讀考試當時那一版的全文，判斷條文是否寫出正解。兩邊都判「對得上」、而且條號相同，才算有依據；不一致的就不放法規重點。
2. **寫摘要**：照寫作規格寫一句摘要。
3. **核摘要**：另一個獨立代理對照全文逐題判「一致」或「偏離」。偏離的修正後，由**新的代理整份重判**，不只重判改過的那幾題，直到全部一致。
4. **防竄改**：建置只用最新一輪鎖定後、摘要檔沒被改過的版本（已實作，突變驗過）。

### 我們寫的（丙）：抽樣複核

**這一層沒有真值。** 「寫得對不對」不是可以核對的東西，不列為核對項目。

能核對的只有下面五項（**C3 機械全量、C1 全量**、其餘抽樣；2026-10-14 Dispatch 補：C1 是五項裡唯一會直接害他答錯的，所以全量）：

| 代號 | 核對什麼 | 怎麼判 |
|---|---|---|
| **C1 不跟官方正解矛盾** | 說明的結論指向官方正解；沒有暗示別的選項才對，也沒有說官方答案錯 | 有任何一處矛盾 → 不合格 |
| **C2 沒有延伸** | 只解釋為什麼正解對；沒有引進題目和選項裡都沒有的數字、期限、金額、條件或規定 | 出現新的數字或條件 → 不合格（這是最容易錯的部分） |
| **C3 沒有偷渡依據** | 不出現法規名稱、「依據」、「依…規定」、「主管機關規定」等 | **建置時機械檢查，全量**；出現就擋下 |
| **C4 不是空話** | 標「說明」的段落要給出比重述答案更多的理由 | 只是把答案換句話說 → 不合格（應該改成「沒有說明」） |
| **C5 內部一致** | 提到的選項編號對得上；段落沒有自相矛盾 | 有錯 → 不合格 |

**C1 全量怎麼做**：每一段都由一個獨立代理看「題目、官方正解、說明」，判「不矛盾／矛盾」。每段很短，不需要讀法規，所以做得到全量（內控約 700 段、約 7 個代理、約 0.4M token）。矛盾的那一段由新的寫手重寫，再由新的核對者重核，直到不矛盾。下面的抽樣仍然照樣抽 C1，當作第二道檢查。

**抽樣**（C2、C4、C5，以及 C1 的第二道）：
- 以「寫手批次」分層：同一個寫手代理一次寫的 50 題算一批，因為錯誤會跟著同一個寫手出現。
- 每批隨機抽 **8 段或 15%**，取較多的一方。
- 抽樣用固定種子：20261014 加上批次編號，可以重現。
- 抽樣在那一批**寫完並鎖定之後**才進行。

**誰核**：
- 由另一個獨立代理核，不是寫手本人。
- 核對者只看題目、官方正解、說明本身，看不到是哪個寫手寫的。

**不合格怎麼處理（事先定）**：

| 抽到的結果 | 處理 |
|---|---|
| 抽樣裡有任何一段 C1 不合格（表示全量 C1 漏掉了） | **整批退回**，由新的寫手重寫，再重新做全量 C1 與抽樣 |
| C2、C4、C5 合計不合格 ≥ 2 段 | **整批退回**重寫 |
| C2、C4、C5 合計不合格 1 段 | 只修那一段，由新的核對者重核那一段；**另外加抽 8 段**，加抽若再有不合格就整批退回 |
| 全部合格 | 該批通過 |

**防竄改**：涵蓋這一層。每批通過時鎖定雜湊；建置時只要「我們寫的」檔在鎖定後被改過，就擋下。

**限度（照寫）**：
- 抽樣核的是形式（矛盾、延伸、依據、空話、一致），不是內容對不對。
- 通過的批次裡，沒被抽到的段落仍可能有錯。
- 寫手、核對者都是 Claude。
- 畫面上的「未查證」標示就是為了這一點。

## 二、順序（Dispatch 定案）

1. **內控先做。**
   - 先逐題歸章（801 題）。
   - 再做「第二章」整章：建議選「逾期放款、催收、呆帳與債權保全」，法規題多，乙、丙、純背都會有。
   - 做完**給使用者看**，他確認後才做內控其餘各章。
2. **內控做完再做金融市場常識與職業道德。**
   - **暫停，等使用者決定**（Dispatch 2026-10-14）：這一科做出來會整份沒有任何一句有外部依據。
   - 量過（同內控那一套抓法規名稱的規則）：116 年版考試範圍 1,174 題裡，**題幹點名法規的只有 40 題（3.4%）**——常識 25／558、道德 15／616，共 28 部不同的法規（最多的是信託法 5、證券交易法 4、信託業法 4）；只寫「依規定」沒點名的 4 題。內控用同一套規則是 202／801（25%）。
   - 所以就算補抓法規版本，法規重點最多也只涵蓋約 3%，實際對得上的會更少——**這一科實質上只能是「我們寫的」或「沒有說明」**。
